# Bancarrota Hídrica — sitio web

Sitio web estático realizado en HTML y CSS para presentar el proyecto de Química
“Bancarrota Hídrica - Contaminación Río Bogotá”.

## Estructura

- `index.html` — página completa.
- `styles.css` — estilos y diseño responsive.
- `assets/logo-crbg.png` — logo del proyecto.
- `assets/matriz-vester.png` — matriz de Vester.
- `assets/clasificacion-vester.png` — gráfica de clasificación.

## Uso

Abre `index.html` en un navegador.

El diseño utiliza:
- **Montserrat** en negrita para títulos y subtítulos.
- **Open Sans Condensed** para el texto.
- Una paleta basada en escalas de verdes.
- Diseño responsive para escritorio, tablet y móvil.

Las fuentes se cargan desde Google Fonts cuando hay conexión a Internet.
